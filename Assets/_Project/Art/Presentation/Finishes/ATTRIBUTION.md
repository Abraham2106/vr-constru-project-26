# Furniture finishes

- Walnut Veneer — Jenelle van Heerden / Poly Haven, CC0: https://polyhaven.com/a/walnut_veneer . Source width 1.8 m; fine vertical grain. 2K diffuse, OpenGL normal and roughness.
- Rough Linen — Poly Haven, CC0: https://polyhaven.com/a/rough_linen . 1K normal/roughness and diffuse luminance recolored to warm cream. Mapped at 0.25 m per repeat as the project upholstery finish.
- Microcement — original procedural material created for this project, 1K seamless maps, 0.5 m per repeat. Subtle color and relief, without prepainted lighting.

Official download manifests and MD5 hashes verified. Source roughness is packed into alpha smoothness (1-roughness); metallic RGB=0. Walnut finish roughness is bounded to 0.43..0.61; linen to 0.84..0.97. Normal maps remain linear OpenGL Y+. Albedo is sRGB. All rendered materials use native URP/Lit.
